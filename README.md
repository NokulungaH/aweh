# Aweh 🇿🇦

**South Africa is online.**

Aweh is a mobile-first community chat concept inspired by the simplicity and personality of early mobile chat, redesigned for today.

## Phase 1

This repository currently contains an interactive front-end prototype built with HTML, CSS and vanilla JavaScript. It includes onboarding, usernames, room discovery, simulated public chat, private-chat previews, profiles, presence statuses, local settings and a data-saver toggle.

> Phase 1 does **not** yet provide real accounts or realtime messaging. Those require a backend and will be introduced in a later phase.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Roadmap

- Realtime authentication and messaging
- Persistent rooms and direct messages
- Presence and notifications
- Blocking, reporting, moderation and anti-spam controls
- Media and voice notes
- PWA / mobile packaging

Built as a lightweight, mobile-first web experience.
